# 使用者操作手冊 (User Manual)

本手冊旨在協助一般使用者快速上手「三廠區物流暨物料簽核系統」，完成 BOM 建立、物料轉移申請與簽核等日常操作。

> **測試帳號 (系統預設)**
> 使用者於畫面左側的快速登入區選擇對應的角色即可直接登入，無需輸入密碼。

---

## 1. 登入與介面介紹

1. 使用瀏覽器開啟 `frontend/index.html`。
2. 在左側快速登入區點選您的角色 (例如：`林員工 (EMP001)`)，系統將自動取得 JWT 並登入。
3. 登入後，左側導覽列顯示目前可用的功能模組：
   - 🏠 **儀表板**：單據統計總覽
   - 📋 **BOM 申請**：建立與提交物料清單
   - 🚛 **物料轉移申請**：建立跨廠區或廠內物料轉移單
   - ✅ **待簽核清單**：需要您審核的單據
   - 🔍 **查詢與追蹤**：查詢所有歷史單據

---

## 2. 建立 BOM 申請 (BOM Application)

**適用角色**：台南廠員工、高雄廠員工（台北場 TPE 不可發起）

1. 點選左側導覽的「📋 BOM 申請」。
2. 在表單中填寫：
   - **廠區**：選擇 `台南廠 (TNN)` 或 `高雄廠 (KHH)`
   - **產品編號**：輸入對應的產品 ID
   - **物料明細**：點選「➕ 新增物料」，輸入物料編號與數量
   - **勾選旗標**：若為高風險 BOM 或成本影響較大，請勾選對應選項（將觸發加簽流程）
   - **建立原因**：簡述 BOM 建立的理由 (上限 500 字)
3. 點擊「儲存草稿」或直接點擊「提交簽核」。

> ⚠️ **系統防呆**：若物料已停用 (DISABLED)，系統將自動阻擋並駁回。

---

## 3. 建立物料轉移申請 (Material Transfer)

**適用角色**：台南廠員工、高雄廠員工

1. 點選左側導覽的「🚛 物料轉移申請」。
2. 在表單中填寫：
   - **來源廠區 / 來源倉庫**：選擇物料從哪個廠區與倉庫移出
   - **目標廠區 / 目標倉庫**：選擇物料要移入哪個廠區與倉庫
   - **物料編號 / 數量**：填寫要轉移的物料與數量
   - **急件旗標**：若為緊急需求，勾選此項
3. 點擊「提交簽核」。

> ⚠️ **系統防呆**：
> - 數量超過 ERP 可用庫存 → 自動駁回
> - 來源與目標倉庫相同 → 自動駁回
> - 數量超過安全上限 (1000) → 自動駁回

---

## 4. 待簽核清單與簽核操作 (Pending Approvals)

**適用角色**：生產主管、廠區主管、倉庫主管、台北財務

1. 點選左側導覽的「✅ 待簽核清單」，查看所有等待您審核的單據。
2. 點擊任一單據，進入**單據詳情**頁面，可查看：
   - 單據基本資訊 (廠區、物料、申請人)
   - 目前簽核進度 (第幾關 / 共幾關)
   - 歷史簽核日誌 (Approval Log)
3. 執行以下操作：
   - 點擊「✅ 同意」→ 核准此單據，並自動進入下一關
   - 點擊「❌ 駁回」→ 填寫駁回原因後送出，單據退回申請人修改
4. 若所有關卡皆通過，系統將自動觸發會計系統同步，單據狀態轉為 `CLOSED`。

---

## 5. 查詢與追蹤 (Search & Track)

**適用角色**：所有人（資料可見度依廠區與職位過濾）

1. 點選左側導覽的「🔍 查詢與追蹤」。
2. 透過上方的搜尋列篩選：
   - **文件類型**：BOM / 物料轉移
   - **狀態**：DRAFT / APPROVING / APPROVED / CLOSED / REJECTED 等
   - **申請人 ID**：輸入特定員工 ID 進行過濾
3. 點擊單據 ID 可進入詳情，查看完整的簽核歷程。

---

## 6. 簽核狀態說明

| 狀態代碼 | 意義 |
| :--- | :--- |
| `DRAFT` | 草稿，申請人尚未提交 |
| `SUBMITTED` | 已提交，等待系統產生簽核關卡 |
| `APPROVING` | 簽核進行中，等待關卡審核 |
| `APPROVED` | 所有關卡通過，等待會計系統同步 |
| `CLOSED` | 完成，已同步至會計系統 |
| `REJECTED` | 已駁回（人工或系統自動） |
| `CANCELED` | 申請人主動撤回 |
| `SYNC_FAILED` | 會計同步失敗，需財務人員手動重試 |

---

## 7. 常見 FAQ

**Q: 我提交了單據，為什麼狀態一直是 REJECTED？**
A: 可能是 ERP 庫存不足、物料已停用，或廠區不符合規則（例如 TPE 不可申請 BOM）。請查看單據詳情中的「駁回原因」欄位。

**Q: 我是簽核人，但找不到應該簽的單據？**
A: 請確認您的登入帳號角色與職位是否符合該簽核關卡要求的角色。例如，台南倉庫主管 (`WH-TNN`) 無法代替高雄倉庫主管 (`WH-KHH`) 簽核。

**Q: 單據最後顯示 SYNC_FAILED，我該怎麼辦？**
A: 此狀態代表會計系統同步失敗。請聯繫台北財務人員，進入單據詳情後點擊「🔄 重試會計同步」按鈕即可手動觸發重試。
